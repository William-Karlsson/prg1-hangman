# Hangman

Välkommen till Hangman! :D

Denna enkla Python app har två primära lägen:
- En spelare
- Två spelare

I enspelarläget väljs ett ord ur en nedladdad ordlista, i tvåspelarläget väljer ena spelaren ett ord den andra ska gissa!

Programmet var skapat för Python 3.13.15. För att starta appen, kör main.py.
